# Docker Hub
docker login

docker tag tarjeta-notas-v2:1.0 jezuz1904/tarjeta-notas-v2:1.0
docker tag to-do-list-v1:1.0 jezuz1904/to-do-list-v1:1.0
docker images | grep jezuz1904

Publicacion de las imagenes en Docker Hub:

docker push jezuz1904/tarjeta-notas-v2:1.0
docker push jezuz1904/to-do-list-v1:1.0

Descarga de las imagenes publicadas:

docker pull jezuz1904/tarjeta-notas-v2:1.0
docker pull jezuz1904/to-do-list-v1:1.0

Creacion de contenedores a partir de las imagenes descargadas:

docker container run -d \
-p 3000:3000 \
--name DOCKER-HUB-TARJETA-NOTAS-V2 \
jezuz1904/tarjeta-notas-v2:1.0

docker container run -d \
-p 5000:5000 \
--name DOCKER-HUB-TODO-LIST-V1 \
jezuz1904/to-do-list-v1:1.0


# AWS ECR

Creación de los repositorios privados en ECR:
Mediante AWS CLI

aws ecr create-repository --repository-name tarjeta-notas-v2 --region us-east-1
aws ecr create-repository --repository-name to-do-list-v1 --region us-east-1

Tageamos las images

docker tag jezuz1904/tarjeta-notas-v2:1.0 301745145877.dkr.ecr.us-east-1.amazonaws.com/tarjeta-notas-v2:1.0
docker tag jezuz1904/to-do-list-v1:1.0 301745145877.dkr.ecr.us-east-1.amazonaws.com/to-do-list-v1:1.0

Publicacion de las imagenes en ECR:

docker push 301745145877.dkr.ecr.us-east-1.amazonaws.com/tarjeta-notas-v2:1.0
docker push 301745145877.dkr.ecr.us-east-1.amazonaws.com/to-do-list-v1:1.0

Descarga de las imagenes publicadas en ECR:

docker pull 301745145877.dkr.ecr.us-east-1.amazonaws.com/tarjeta-notas-v2:1.0
docker pull 301745145877.dkr.ecr.us-east-1.amazonaws.com/to-do-list-v1:1.0

Creacion de contenedores a partir de las imagenes descargadas desde ECR:

docker container run -d \
-p 3000:3000 \
--name ECR-TARJETA-NOTAS-V2 \
301745145877.dkr.ecr.us-east-1.amazonaws.com/tarjeta-notas-v2:1.0

docker container run -d \
-p 5000:5000 \
--name ECR-TODO-LIST-V1 \
301745145877.dkr.ecr.us-east-1.amazonaws.com/to-do-list-v1:1.0
